## 🚀 Getting Started

To run the portfolio locally:

### 1. Clone the repository

```bash
git clone https://github.com/sabujrana/My-Portfolio.git
```

### 2. Open the project

```bash
cd My-Portfolio
```

### 3. Open the website

Open `index.html` directly in your browser, or use the **Live Server** extension in VS Code.

## 🚀 Deployment

The portfolio can be deployed using **Netlify**.

Recommended workflow:

```text
Local Project
     ↓
Git
     ↓
GitHub
     ↓
Netlify
     ↓
Custom Domain
```

### Netlify Deployment

1. Push the project to GitHub.
2. Sign in to Netlify with GitHub.
3. Import the repository.
4. Select the `main` branch.
5. Leave the build command empty for this static website.
6. Use the project root as the publish directory.
7. Deploy the site.
8. Add the custom domain.

Example custom domain:

```text
https://ranasabuz.com
```

## 🔄 Updating the Website

After making changes locally:

```bash
git add .
git commit -m "Update portfolio"
git push origin main
```

When the GitHub repository is connected to Netlify, the updated version can be deployed automatically.
